# БИЗНЕС-ДОМЕН. КОНТАКТ-ЦЕНТР СТРАХОВОЙ КОМПАНИИ

В качестве примера системы массового обслуживания рассмотрим работу контакт-центра страховой компании, который принимает первичные обращения клиентов о наступлении страховых случаев (ДТП, повреждение имущества и т. п.). Страховые случаи наступают у клиентов независимо друг от друга, а после массовых событий нагрузка резко растёт. Операторы не успевают обработать все обращения, поэтому автоматизированная система распределяет их по свободным операторам, ставит в очередь и при переполнении очереди отклоняет часть обращений.
